# Sêmen MF do Brasil

Site institucional da **Sêmen MF do Brasil**, empresa de Uberaba (MG) que exporta genética zebuína para a África, a Ásia e a América Latina.

**No ar:** [mfdobrasil.com](https://mfdobrasil.com) · Cartão de visita digital: [mfdobrasil.com/daniel](https://mfdobrasil.com/daniel/)

## Destaques

- Página única em HTML, CSS e JavaScript puros, sem framework nem etapa de build
- Três idiomas (português, francês e inglês) com troca instantânea, idioma lembrado no navegador e seleção por link (`?lang=fr`)
- Pensado para celular primeiro, com imagens em tamanhos reduzidos, carregamento sob demanda e vídeos leves
- Galerias com visualizador de fotos em tela cheia
- Metadados de compartilhamento (Open Graph) para prévias no WhatsApp e nas redes sociais
- Cartão de visita digital com botão de WhatsApp com mensagem pronta, contato para salvar na agenda (vCard), QR code e compartilhamento nativo

## Estrutura

```
index.html        site completo
daniel/index.html cartão de visita digital
img/              fotos e logo
video/            vídeos do site
```

## Como rodar

Basta abrir o `index.html` no navegador ou servir a pasta com qualquer servidor estático. A publicação é feita enviando os arquivos para o `public_html` da hospedagem.

## Manutenção

Como configurar outro computador, editar os textos nos 3 idiomas, publicar e o que está pendente: veja **[MANUTENCAO.md](MANUTENCAO.md)**.
